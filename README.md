# بُنيان · BUNYĀN — مكتب التصميم الهندسي والمعماري

موقع تعريفي **احترافي (بريميوم)** لمكتب تصميم هندسي ومعماري — جاهز للنشر، وقابل للتخصيص لأي مكتب لا يملك موقعاً إلكترونياً.

> **«من الفكرة إلى البنيان · From concept to structure.»**

## ما يميّز الموقع
- تصميم بريميوم بالعربية (RTL) — متجاوب بالكامل مع الجوال واللوحي والحاسب.
- هوية بصرية هندسية (إسمنت + برونز) بطابع «المخططات المعمارية» (Blueprint).
- رسومات معمارية متجهية (SVG) بالكامل — **بدون أي صور خارجية**، فيخفّ الموقع ويعمل في أي مكان.
- صفحة واحدة متكاملة: الواجهة · عن المكتب · الخدمات · المنهجية · الأعمال · الإحصائيات · لماذا نحن · آراء العملاء · التواصل.
- نموذج تواصل يرسل الطلب مباشرةً عبر **واتساب**.
- متوافق مع GitHub Pages — ملف واحد `index.html` بلا أي اعتماديات بناء.

## الخدمات المعروضة
التصميم المعماري · التصميم الداخلي · التصميم الإنشائي · الإشراف الهندسي · الإظهار ثلاثي الأبعاد · الرخص والتراخيص.

## كيف تجعله موقع مكتبك (تخصيص سريع)
كل البيانات تجريبية (Placeholder) — استبدلها داخل `index.html`:
1. **الاسم والشعار:** «بُنيان» / `Bunyān` في الترويسة والتذييل والشعار (SVG).
2. **رقم الواتساب:** المتغيّر `WA` في السكربت، وروابط `wa.me/966500000000`، و`tel:` والبريد في قسم التواصل والتذييل.
3. **العنوان وأوقات العمل** في قسم «تواصل معنا» والتذييل.
4. **الأعمال:** استبدل التصاميم التوضيحية (SVG) بصور مشاريع المكتب الفعلية.
5. **الإحصائيات وآراء العملاء** بأرقام وأسماء حقيقية.

## التشغيل محلياً
افتح `index.html` في المتصفح مباشرةً، أو:
```bash
python3 -m http.server 8000
```

## النشر على GitHub Pages
Settings → Pages → Branch: فرع النشر → `/ (root)`.
